# Minishell — Day 1

## Objective
Plan shell features and parse user input.

## Features Implemented
- Custom prompt: `minishell>`
- Read user input and parse arguments
- Built-in commands:
  - `cd`
  - `pwd`
  - `exit`
- Execute external commands using `fork()` and `execvp()`

## How to Run
```bash
make
./minishell
